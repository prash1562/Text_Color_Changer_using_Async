# Random HEX Color Generator 🎨

A simple JavaScript DOM project that generates random HEX colors and changes the text color automatically every second.

## 🚀 Features

- Generate random HEX color codes
- Change text color dynamically
- Start and Stop buttons
- Beginner-friendly JavaScript project
- Uses `setInterval()` and `clearInterval()`

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

## 📂 Project Structure

```bash
project-folder/
│

```

---

## ⚡ How It Works

1. Click the **Start** button
2. JavaScript generates a random HEX color
3. The text color changes every second
4. Click **Stop** to stop the animation
